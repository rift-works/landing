A search field. Results appear only while focused and non-empty.

```jsx
<SearchField value={q} onChange={setQ} results={[
  <><b style={{fontWeight:600}}>Arqui</b>tectura de datos</>
]} />
```

The result count line is mono and always present when the panel is open. The `⌘K` hint is a typographic glyph — there is no search icon in this system.
