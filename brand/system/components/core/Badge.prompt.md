A status marker — outlined, mono, uppercase, square.

```jsx
<Badge>En curso</Badge>
<Badge tone="positive">Entregado</Badge>
<Badge tone="negative">Vencido</Badge>
<Badge tone="muted">Pendiente</Badge>
```

The label must name the state in words. A bare coloured dot or an unlabelled badge is off-brand — colour never carries meaning alone.
