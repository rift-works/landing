# RiftWorks Landing

Landing corporativa de [RiftWorks](https://weareriftworks.com) construida en Next.js a partir del sistema de marca del repositorio.

## Páginas

- `/` — Home: problema, posicionamiento, capacidades, modelo de entrega y contacto
- `/capacidades` — Engineering, Data & AI, Product Design, Strategy
- `/nosotros` — Manifiesto, fundadores y principios
- `/contacto` — Formulario **Iniciar un proyecto** / Start a Project

El copy y la identidad visual salen de `brand/`: estrategia, voz, tokens y firma Wordmark-led + Señal de retorno.

## Desarrollo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm run start
npm run lint
```

## Marca

Tipografía: Manrope, Inter, IBM Plex Mono. Color: Deep Navy `#0B1F33`, Signal Blue `#1F6FEB`, Coast Teal `#16B8A6`, Cloud White `#F7FAFC`.
